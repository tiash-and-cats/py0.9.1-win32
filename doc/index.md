## Windows build

You can get a precompiled build for Windows over [here](https://github.com/tiash-and-cats/py0.9.1-win32/releases).

Note that the following modules are unavailable:

- `posix`
- `amoeba`
- `audio`
- `pnl`
- `path`
- `posix`
- `panel`
