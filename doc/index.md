## Problems with these old docs

They have a million gaps that Guido didn't fill in, so these docs are more of an outline. You can find out more by [seeing the source code](https://github.com/tiash-and-cats/py0.9.1-win32/).

## Windows build

You can get a precompiled Python 0.9.1 build for Windows over [here](https://github.com/tiash-and-cats/py0.9.1-win32/releases).

Note that the following modules are unavailable:

- `posix`
- `amoeba`
- `audio`
- `pnl`
- `path`
- `posix`
- `panel`
